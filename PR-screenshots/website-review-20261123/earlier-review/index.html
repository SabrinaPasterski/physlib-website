physlib.io review: before and after

Left is the site as it is live today. Right is the review branch, running locally. Nothing here is deployed or committed. Site-wide on the right: a section label above every title, one title style, darker grey text, a reserved left column so pages stop jumping, and previous/next links at the bottom.

PR Queue

Large change. The queues are built from GitHub directly, so the page works whether or not the Zulip bot's feed is up. One intro sentence, a search box, and five number tiles that are the filters. Labels use the site's light tag tones (blue for topics, amber for anything holding a PR up, grey for the rest), and the table shows 25 rows per page.

Find a Task

Large change. Counts on every tab, a line of helper text per tab, common-search chips, a New here? line, and filters kept in the URL so a view can be shared.

References

Large change. Search also covers year and Lean file path, each entry has Copy link, and entries with no URL get a Google Scholar search link. The list now shows 20 per page with Previous and Next at the bottom, and Show citations sits on the same line as the reference key.

Project Ideas

Large change. Nothing on this page is hand-written. Topics are grouped by how many claims are left, then topics whose roadmap is written but not started, then areas with Lean files and no roadmap at all, each with a link to write one. Individual tasks stay on Find a Task.

Ways to Contribute

Ten entries in four groups, easiest first for a curious physicist. A Which describes you? filter (New to Lean, I know Lean, I use AI tools) narrows the list; the AI choice shows a PhyslibAlpha entry. Every entry has a button to the page where you do it, and Spread the Word has share links.

Getting Started

Mostly unchanged in look: corrected instructions, darker grey text, previous/next links at the bottom.

Monthly Updates

The 15 older PDF-only reports (May 2024 to Jul 2025) are now listed in the month sidebar behind a collapsed Earlier reports toggle. Title style matches the rest of the site.

About

Value and audience cards are now sub-headings under their section.

Team

Section label above the title and a Monthly Updates button leading to the next About page.
